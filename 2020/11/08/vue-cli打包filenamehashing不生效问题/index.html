vue-cli打包filenameHashing不生效问题

发表于 2020-11-08
  • 小家猫的笔记
首页 vue

# 问题

自己的一个 vue2.x 项目，发现发布的时候有缓存问题，查阅官方文档发现 vue.config.js 有 filenameHashing 这个配置且默认是开启的，但是本地打包一直不生效，而且发现配置的打包插件（例如代码压缩）也不生效，

再次查阅官方文档，在环境变量配置时发现了问题所在，找到下图文档，文档链接 https://cli.vuejs.org/zh/guide/mode-and-env.html#% E6% A8% A1% E5% BC%8F

# 解决方案

  1. 找到项目中的.env.xxx 文件，我的配置文件命名是.env.prod

  2. 在文件头部增加 NODE_ENV = 'production'

  3. 再次打包查看 dist 目录生成文件命名是否已经 hash
